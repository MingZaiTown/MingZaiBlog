## 一、5G小区选择与重选（RRC_IDLE / INACTIVE状态）

### 1. 基本概念
- **小区选择**：UE在PLMN选定后，寻找合适小区驻留。
- **小区重选**：UE寻找更优小区并重选，若TAC变化则发起位置登记。

### 2. 小区接入限制
| 参数 | 说明 |
|------|------|
| `cellBarred` | MIB指示，普通UE不能接入barred小区（如测试小区） |
| `cellReservedForOperatorUse` | 仅允许接入等级11、15的UE接入 |
| `cellReservedForOtherUse` | 禁止UE接入 |

### 3. 小区选择准则（必须同时满足）
- **Srxlev > 0** 且 **Squal > 0**

#### 公式：
- $Srxlev = Q_{rxlevmeas} - (Q_{rxlevmin} + Q_{rxlevminoffset}) - P_{compensation} - Q_{offsettemp}$
- $Squal = Q_{qualmeas} - (Q_{qualmin} + Q_{qualminoffset}) - Q_{offsettemp}$

> 示例：若最小接入RSRP为-120dBm，则配置参数需使测量值满足Srxlev > 0。

### 4. 小区重选优先级
- 通过**异频载波优先级**配置（高/低优先级）
- 优先级决定是否启测和判决规则

### 5. 邻区启测条件
| 优先级 | 启测条件 |
|--------|-----------|
| 同频 | Srxlev ≤ SIntraSearchP 或 Squal ≤ SIntraSearchQ |
| 异频/异系统（高） | 始终测量 |
| 异频/异系统（同/低） | Srxlev ≤ SnonIntraSearchP 或 Squal ≤ SnonIntraSearchQ |

### 6. 重选判决规则
- **高优先级**：只要邻区质量 > 阈值，即可重选
- **同优先级**：使用R准则（排序）
- **低优先级**：服务小区质量低于阈值，且邻区质量高于阈值

### 7. UE移动状态检测
| 状态 | 条件（在T_CRmax内重选次数） |
|------|-----------------------------|
| 正常 | < N_CR |
| 中速 | N_CR_M ≤ 次数 < N_CR_H |
| 高速 | > N_CR_H |

> 移动状态会**缩放重选参数**，加快高速移动下的重选。

## 二、5G切换流程及参数（RRC_CONNECTED状态）

### 1. 切换触发原因
- 无线环境（信号质量、电平、距离、速度）
- 网络原因（负荷均衡）
- OAM干预

### 2. 切换三部曲
1. **测量**：UE根据测量控制上报事件（A1~A6, B1, B2）
2. **判决**：gNB选择目标小区和切换策略
3. **执行**：资源申请、切换命令下发、数据转发

### 3. 测量对象
- 基于SSB或CSI-RS
- 同频/异频测量（中心频率或子载波间隔不同）

### 4. 测量控制参数（RRC重配置）
- `measObject`：测量对象（频点、带宽、Smtc等）
- `reportConfig`：事件或周期上报
- `measId`：关联测量对象和上报配置

### 5. 常见测量事件（重点）
| 事件  | 触发条件                     | 典型应用    |
| --- | ------------------------ | ------- |
| A1  | 服务小区 > 门限                | 停止测量    |
| A2  | 服务小区 < 门限                | 启动测量    |
| A3  | 邻区 > 服务小区 + 偏置           | 同频/异频切换 |
| A4  | 邻区 > 门限                  | 负荷均衡    |
| A5  | 服务小区 < 门限1 且 邻区 > 门限2    | 信号差时的切换 |
| B1  | 异系统邻区 > 门限               | 异系统切换   |
| B2  | 服务小区 < 门限1 且 异系统邻区 > 门限2 | 异系统语音切换 |

> 每个事件都有**进入/离开条件**，涉及Hys（迟滞）、Off（偏置）、Thresh（门限）。

### 6. 切换参数配置（工程实践）
- **NR邻基站**：MCC、MNC、gNB ID
- **SCTP偶联**：目标基站IP、Xn链路
- **路由关系**：对端IP网段+掩码
- **异频载波信息**：频点、优先级、运营商标识
- **A1/A2/A3/A4/A5事件参数**：门限、迟滞、触发时间
- **邻小区关系 & 外部小区**：中心频点、带宽、POINTA信道号计算

### 7. 切换流程
- 站内切换、站间切换（Xn或N2接口）
- 包括：测量上报、切换请求、资源分配、RRC重配、切换完成
