# 7月26日
#### 11:35~22:11 🚄兰州➡️贵阳，入住酒店住一晚

# 7月27日
#### 9:46~10:27 🚄贵阳➡️安顺
#### 14:00~17:00 游玩黄果树瀑布
陡坡塘瀑布、大瀑布+水帘洞，时间不够需要舍弃天星桥
#### 20:00 返回安顺市区住一晚
可逛安顺夜市等

# 7月28日
#### 11:12~15:39 🚄安顺➡️大理
下午可逛大理古城
#### 晚上住大理住一晚
酒店建议住大理古城南门附近
# 7月29日
#### 整天 游玩洱海，晚上住大理再住一晚
可以租车游玩洱海：
大理古城 → 喜洲古镇，喜洲 → 双廊古镇，双廊 → 鹿卧山 → 小普陀，小普陀 → 理想邦 → 兴盛大桥 → 返回古城。
# 7月30日
#### 9:00~12:00 🚄大理➡️昆明
住翠湖公园附近或南屏步行街周边
#### 14:00~晚上 昆明游玩，在昆明住一晚
在昆明吃各种小吃

# 7月31日
#### 返程，但是昆明到兰州没有动车，需考虑飞机或者到贵阳再到兰州

# 补充 
#### 没有计划到的地方：荔波、梵净山、丽江、香格里拉、西双版纳。丽江离大理比较近，可以考虑纳入行程
