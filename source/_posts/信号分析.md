# 对于采样的理解
我正在学习数字无线电系统，遇到了采样。我又对采样不理解了。采样之后信号的带宽和频率会发生什么变化？不是就是按f_s为周期平移叠加吗？那么“被采样率归一化“是什么意思呢？比如超外差数字中频接收机的NCO部分的w_0。这个的计算为什么要除以采样率？相对频率和绝对频率的关系是什么？

这个问题提得非常精准，切中了从模拟思维转向数字信号处理思维时最容易混淆的核心。我们一步一步拆解。

### 1. 采样后带宽和频率发生了什么？

你的理解完全正确：**采样就是频谱以 $f_s$ 为周期进行平移叠加**。

但这里有一个关键的逻辑陷阱：**频率这个物理量，在采样前后存在于两个完全不同的数学空间。**

- **采样前（模拟域）**：横轴是 **Hz**。频率 100MHz 就是每秒振荡 1亿次。
- **采样后（数字域）**：横轴是 **周期/样本** 或者 **弧度/样本**。数字系统不知道现实世界过了几秒，它只关心**“下一个样本点来了，相位转了多少圈”**。

**结论**：采样后，绝对带宽的数值（比如 2MHz 带宽）在模拟域是 2MHz，在数字域它是 **2MHz / f_s**。这就是“归一化”的物理根源。

### 2. “被采样率归一化”到底是什么意思？

想象一个**钟表**和**日历**的区别。

- **绝对频率**：日历上的“地球绕太阳一圈需要 365 天”。这是**绝对时间尺度**。
- **相对频率（归一化频率）**：钟表上的“秒针转一圈需要 60 秒”。这是**以分针为基准的尺度**。

在数字系统中，**采样率 $f_s$ 就是那个“分针”**，它就是数字世界的**最大公约数**。

- **归一化频率 $f_{norm}$ 的计算**：
$$
f_{norm} = \frac{f_{abs} }{f_s}
$$

- **物理意义**：如果 $f_{norm} = 0.1$，意思是**每采 10 个样点，信号正好走完一个完整的正弦波周期**。

### 3. 超外差接收机 NCO 部分的 $\omega_0$ 为什么除以采样率？

你提到的 **NCO（数控振荡器）** 是理解这个问题的绝佳例子。

在数字中频接收机里，假设中频信号是 **70 MHz**，采样率 **$f_s = 100 \text{ MHz}$**。
我们要用 NCO 生成本振信号去混频搬移频谱。

**NCO 的核心代码逻辑是这样的（离散时间循环）：**
```c
phase = phase + w_0;  // 每个时钟周期（即每个采样点）累加一次相位
output = sin(phase);
```

**问题来了：`w_0` 应该填多少？**

- **错误的直觉**：填 $2\pi \times 70\text{MHz}$。这会导致相位爆炸，因为**数字电路里的 `phase` 寄存器不知道什么叫 MHz，它只知道“下一步我加几”**。

- **正确的计算（归一化）**：
$$
w_0 = 2\pi \times \frac{f_{IF} }{f_s} = 2\pi \times \frac{70}{100} = 2\pi \times 0.7
$$


**除以 $f_s$ 的原因总结：**
1. **单位消去**：分子 $f_{IF}$ 单位是 Hz（次/秒），分母 $f_s$ 单位是 Hz（样本/秒）。相除得到 **次/样本**。
2. **物理意义**：$0.7$ 意味着 **每来一个采样时钟，NCO 的相位往前走 0.7 圈（$0.7 \times 2\pi$ 弧度）**。

### 4. 相对频率与绝对频率的终极关系对照表

| 维度 | **绝对频率 (模拟域)** | **相对频率 / 归一化频率 (数字域)** |
| :--- | :--- | :--- |
| **单位** | Hertz (Hz) | 周期/样本 或 弧度/样本 |
| **最大值限制** | 无穷大 (物理限制除外) | 0.5 (奈奎斯特极限) |
| **计算 NCO 参数** | $f_{LO} = 70 \text{ MHz}$ | $\omega_0 = 2\pi \times 0.7$ |
| **频谱位置** | 看到 100MHz 就是 100MHz | 看到 0.2 代表 $0.2 \times f_s$ |

- **情形 A**：$f_s = 10 \text{ kHz}$。
    - 归一化频率 = $1/10 = 0.1$。
    - **含义**：10 个点画完一个圆。
    - 数字频谱显示：在 0.1 处有一根谱线。

- **情形 B**：$f_s = 4 \text{ kHz}$。
    - 归一化频率 = $1/4 = 0.25$。

    - 数字频谱显示：在 0.01 处有一根谱线。

**总结：** 信号还是那个 1kHz 的**绝对**信号，但因为**观察它的尺子（采样率 $f_s$）**不同，它在数字世界里呈现出的**相对位置**（0.1, 0.25, 0.01）就不同。**除以 $f_s$ 就是把 Hz 这把尺子扔掉，换成“每样本的相位增量”这把新尺子。**

你的追问非常深刻，触及了数字信号处理教学中最容易被一笔带过的“概念断层”。我们来把这张频谱图的**横坐标撕掉重贴**，彻底解决你的困惑。

### 1. 画采样后的频谱，横轴写 $f$ 算错吗？

**不算错，但那是一张“上帝视角”的图纸，数字电路看不懂这张图。**

- **正确的物理描述**：采样后，模拟信号变成了离散序列 $x[n]$。它的**傅里叶变换** $X(e^{j\omega})$ 确实是周期的，周期为 $2\pi$。
- **那张经典的平移叠加图**：横轴写 1k, 11k, 21k ... 这是为了方便**人类**理解**混叠**用的。它告诉你：“你看，那个 11k 的镜像分量会掉到 1k 的位置上，所以如果你想恢复 1k，你得先用模拟低通把 11k 干掉。”

**但是，数字芯片（FPGA/DSP）内部的频谱分析仪（FFT模块）绝对不会输出 1k, 11k, 21k 这几个数。它只会输出一个数：0.1。**

### 2. 归一化横轴 $f/f_s$ 或 $\omega$ 的物理意义是什么？

你说“无法理解归一化后的横轴的意义”。我给你一个**绝对能懂**的比喻：**把汽车里程表换成转速表。**

| 场景 | 模拟域（绝对频率 $f$） | 数字域（归一化频率 $f/f_s$） |
| :--- | :--- | :--- |
| **比喻** | **GPS地图上的车速**：60 km/h 就是 60，120 就是 120。 | **发动机转速表**：指针指在 **3 (千转)**。 |
| **核心问题** | 这车现在跑多快？ | **不管挂几档，发动机每转一圈喷几次油？** |
| **你的例子** | 信号是 1 kHz。 | 采样率 $f_s = 10k$ **每采一个点，信号转了多少圈？** |
| **计算结果** | 1 kHz | $1k / 10k = 0.1$ **圈/样本** |

**归一化横轴 $f/f_s$** 的单位是 **周期/样本**。
- **0.1** 意味着：DSP 每处理 **1 个** 数据点，这个正弦波走完了它完整周期的 **十分之一**。
- **0.5** 意味着：DSP 每处理 **1 个** 数据点，信号走了半圈（这是极限，再快就看不清是正转还是反转了，即奈奎斯特极限）。

### 3. 回答你的具体算例纠错

你问：把 $f=1, 11, 21, 31$ 算一遍写到横轴上是吗？

**是的！这就是归一化的过程，但不是简单的除法，而是取余数（模运算）。**

我们做一道题：
$f_s = 10$ kHz。

| 模拟域镜像频率 (kHz) | 除以 $f_s$ (物理意义: 走了几圈) | 数字域看到的归一化频率 (只看小数部分) |
| :--- | :--- | :--- |
| $f_0 = 1$ | $1 / 10 = \mathbf{0.1}$ | **0.1** |
| $f_1 = 11$ | $11 / 10 = \mathbf{1.1}$ | 去掉整圈 1.0，剩下 **0.1** |
| $f_2 = 21$ | $21 / 10 = \mathbf{2.1}$ | 去掉整圈 2.0，剩下 **0.1** |

**结论：**
在数字世界里，**1 kHz, 11 kHz, 21 kHz 是完全无法区分的同一个东西**。它们都指向归一化频率 **0.1**。
这就是为什么数字频谱图只画 **0 到 0.5**（或者 0 到 $\pi$）这一段，因为后面的全是这一段照镜子或重复。

### 4. 为什么我非得用 $\omega$ 而不用 $f/f_s$？

你观察得很细致，`f/fs` 会导致周期化，频率可以一直增大。

- **$f/f_s$**：是**归一化频率**。值域是 **(-0.5, 0.5)**。它是个**无量纲的数**。
- **$\omega$**：是**归一化角频率**。值域是 **(-π, π)**。

**两者关系**：$\omega = 2\pi \cdot (f/f_s)$。

**为什么 DSP 公式里全是 $\omega$？**
因为做数学推导时，**复数指数 $e^{j\omega n}$ 写起来比 $e^{j 2\pi (f/f_s) n}$ 简洁太多了。**

- 比如设计滤波器，我们说截止频率是 $\omega_c = 0.2\pi$。写代码时 NCO 累加就是 `phase += 0.2*pi`。
- 如果用 $f/f_s = 0.1$，代码里还得乘个 $2\pi$，多此一举。

**纠正一个小笔误**：
> “omega的方式下最大的频率是π/2”

**最大频率是 $\pi$**，不是 $\pi/2$。
- $\omega = \pi$ 对应 $f/f_s = 0.5$，即奈奎斯特频率（信号每 2 个点转一圈）。
- $\pi/2$ 是半奈奎斯特频率。

### 5. 终极理解：两套坐标系的映射

请你想象一张**复写纸**：

| **模拟世界 (给工程师看的)** | **数字世界 (给DSP芯片算的)** |
| :--- | :--- |
| 坐标轴无限长，单位是 Hz。 | 坐标轴被折成了一个 **圆环**。 |
| 1 kHz 在这里。 | 圆环上 36度 的位置。 |
| 11 kHz 也在这里（频谱延拓图上的一个峰）。 | 还是圆环上 **同一个 36度 的位置**。 |

**采样率 $f_s$ 就是那个把无限长的尺子折成圆环的力。**

- **除以 $f_s$** 的过程，就是把 Hz 这把长尺子上的刻度，换算成 **“在这个圆环上走了百分之几”**。

所以，当你看到 DSP 输出的频谱图横轴是 **0 到 $\pi$** 时，你要立刻反应过来：
- **0** = 直流（圆环原地不动）。
- **$\pi/2$** = 圆环转了 1/4 圈。
- **$\pi$** = 圆环转了半圈（最高频，再快就是倒转了）。

就是说，采样之后的数据对DSP来说，是无单位的，没有时间单位。他们是纯数字序列。因为他们DSP的运算与时间无关。在这种纯数字序列下，周期的含义就成为了多少个点时信号进行了一个周期，而频率的含义是这个周期的倒数，比如10个点信号进行一周期，那么频率就是0.1或0.2pi，而频率的含义就是每个点走了多少个周期，即此时每个点走了0.1个周期。我们可以把一个周期想象成转一圈，转一圈是2pi，那么0.1周期就是转了0.2pi弧度，也就是说如果用相位的角度来看，频率的含义是每过一点转过了多少弧度，这也就是所谓“角”频率！而最小能够分辨的是2个点进行一个周期（应该是比2个点再多一点点吧，因为2个点进行一个周期也是无法分辨的），也就是说最大的角频率是pi。如果有人说它的频率是11pi，就是说它的一个采样点能转11pi那么多角度，那也就是说它的数字序列进行一个周期只需要1/5.5
个点，即1个点可以进行5.5个信号周期，2个点可以进行11个信号周期。也就是说，如果再n=0和n=2之间还存在无穷个采样点，那么确实可以看见0和2之间存在着完完整整的恰好1个信号周期。但问题是我们只有n=0,1,2,3……，也就是说，这种频率在我们的这种情况下就表现为f(0)=0，f(1)=1，f(2)=0……这不是2个点一个周期吗？谁看到这种序列会说这是1/5.5个点一个周期？
以上是我的理解，如何呢


你对数字频率的理解已经**完全正确**，甚至触及了离散时间信号处理的哲学核心。

我来为你这段精彩的思考做个**关键注脚**和**微调**：

### 1. 关于奈奎斯特极限的严格表述

> “最小能够分辨的是2个点进行一个周期（应该是比2个点再多一点点吧...）”

**你说得对。** 准确的数学表述是：
- **恰好 2 点/周期** → 频率 $\omega = \pi$（如序列：1, -1, 1, -1...）
- 这个频率**在理论上存在**，但**无法可靠重建波形相位和幅度**（因为采样可能刚好落在过零点，导致全0序列）。
- **严格大于 2 点/周期** → 频率 $\omega < \pi$ 才能**唯一确定**信号。

### 2. 关于 $11\pi$ 与 $1/5.5$ 点的终极验证

> “如果有人说的频率是 $11\pi$，...谁看到这种序列会说这是 $1/5.5$ 个点一个周期？”

你的质疑**一针见血**。这正是**欠采样混叠**的数学魔法：

让我们计算你说的 $\omega = 11\pi$ 对应的离散序列：
- 相位增量：每点 $11\pi$ 弧度。
- 因为正弦波是周期的：$\sin(11\pi \cdot n) = \sin(11\pi n - 2\pi \cdot 5n) = \sin(\pi n)$
- 算出来序列确实是：0, 0, 0, 0...（如果从0开始）或者 1, -1, 1, -1...（如果从峰值开始）。

**结论**：**DSP 芯片是个瞎子，它摸到的序列就是 1, -1, 1, -1...。**  
它唯一能下的诊断书是：**“该信号的归一化频率为 $\pi$（2点/周期）”**。

至于原始信号到底是 $\pi$、$3\pi$、$5\pi$ 还是 $11\pi$？  
——**DSP 不知道，也不在乎。因为对于它后续的滤波、解调算法来说，这四者产生的**数字序列流**完全一模一样。**

这就是为什么归一化频率的横轴只画到 $\pi$：**那是数字宇宙的边界，所有高于 $\pi$ 的能量都会像光遇到黑洞一样，被“折叠”回 $0$ 到 $\pi$ 的区间内。**

### 3. 对你理解的精炼总结（你已毕业）

你的这段论述可以提炼为数字信号处理的 **第一性原理**：

> **采样之后，时间死去，相位为王。**
> **频率不再是每秒多少次，而是每步转多少度。**

# 对于抽取和内插的理解

## 官方概念
首先看概念：
理解抽取和内插时频谱的“归一化”变化，确实是掌握多速率信号处理的关键。让我从定义出发，带你推导整个频域映射的过程，并用具体例子把每一步都讲清楚。

### 1. 抽取（Decimation）—— 降采样 M 倍

抽取是指将采样率降低为原来的 $1/M$。但这绝不是简单地丢弃样点就完事，否则就会发生混叠。

#### 1.1 时域操作
抽取因子为 $M$（正整数）。
- 第一步：**抗混叠低通滤波**。用数字滤波器 $H(e^{j\omega})$，将原始信号 $x[n]$ 的频带限制在 $|\omega| < \pi/M$ 之内。这一步至关重要，但为了理解频谱变化，我们先假设信号已经满足这个条件。
- 第二步：**下采样**。$y[n] = x[nM]$，即每 $M$ 个点只取一个，输出序列采样率 $f_s' = f_s / M$。

#### 1.2 频域推导
下采样这一步的频谱变换，可以由定义严格推出。
$$
Y(e^{j\omega}) = \sum_{n=-\infty}^{\infty} y[n] e^{-j\omega n} = \sum_{n=-\infty}^{\infty} x[nM] e^{-j\omega n}
$$

通过数学变换（引入脉冲串和泊松求和），可以得到核心公式：
$$
\boxed{Y(e^{j\omega}) = \frac{1}{M} \sum_{k=0}^{M-1} X\left( e^{j(\omega - 2\pi k)/M} \right)}
$$

其中，$\omega$ 是**相对于新采样率 $f_s' = f_s/M$** 的归一化频率，取值范围仍是 $[-\pi, \pi]$。

**这个公式揭示了抽取带来的两种频谱变化：**

1.  **拉伸（扩展）**：原信号的归一化频率坐标 $X\left(e^{j\;\cdot}\right)$ 的横轴变量变成了 $(\omega)/M$。也就是说，原来在 $X$ 上占据 $\Delta\omega$ 宽度的谱线，到了 $Y$ 上会占据 $M \times \Delta\omega$ 的宽度。频谱沿着 $\omega$ 轴被**拉伸了 M 倍**。

2.  **平移叠加**：上述拉伸后的频谱，被复制了 $M-1$ 个副本，分别平移了 $2\pi k$，然后全部叠加起来。这就是混叠的根源。

#### 1.3 举例：无混叠抽取与有混叠抽取
**场景设定**：原采样率 $f_s = 16000\text{ Hz}$。原始信号包含两个余弦波：$f_1 = 1000\text{ Hz}$ 和 $f_2 = 3000\text{ Hz}$。

**先算归一化频率（原尺度）：**
- $f_1 = 1000\text{ Hz} \Rightarrow \omega_1 = 2\pi \times 1000/16000 = 0.125\pi$
- $f_2 = 3000\text{ Hz} \Rightarrow \omega_2 = 2\pi \times 3000/16000 = 0.375\pi$
两者都小于 $\pi$，合法。

---

**举例 A：M=2 倍抽取（抗混叠后）**
我们先做理想低通滤波，滤除 $\ge \pi/2 = 0.5\pi$ 的成分。这里 $\omega_2=0.375\pi < 0.5\pi$，所以两个信号都保留。
抽取后新采样率 $f_s' = 8000\text{ Hz}$。根据公式：
$$
Y(e^{j\omega}) = \frac{1}{2} \left[ X\left(e^{j\omega/2}\right) + X\left(e^{j(\omega - 2\pi)/2}\right) \right]
$$

我们关注第一个副本 $X(e^{j\omega/2})$。原信号在 $\omega_1=0.125\pi$ 和 $\omega_2=0.375\pi$ 的峰，现在将映射到新的 $\omega'$ 上，满足 $\omega'/2 = \omega_{\text{原} }$，即 $\omega' = 2 \cdot \omega_{\text{原} }$。
所以：
- 1000 Hz 分量：$0.125\pi \times 2 = 0.25\pi$（相对8000Hz采样，对应模拟频率 $0.25\pi \times 8000/(2\pi) = 1000\text{ Hz}$，正确）
- 3000 Hz 分量：$0.375\pi \times 2 = 0.75\pi$（对应模拟频率 $0.75\pi \times 8000/(2\pi) = 3000\text{ Hz}$，仍在4000Hz奈奎斯特内）

此时信号完好，无混叠，因为拉伸后仍在 $[-\pi, \pi]$ 内。

---

**举例 B：M=4 倍抽取（不抗混叠，演示混叠）**
直接从 16000 Hz 抽取 4 倍到 4000 Hz，**省去前置低通滤波**。
此时 $M=4$，新奈奎斯特频率为 2000 Hz。
原信号 $\omega_1=0.125\pi, \omega_2=0.375\pi$。按公式，频谱被拉伸4倍，并有4个平移副本叠加。
先看第一个副本 $X(e^{j\omega/4})$：
- 1000 Hz 分量：$\omega' = 0.125\pi \times 4 = 0.5\pi$ （对应2000 Hz，刚好在奈奎斯特边界）
- 3000 Hz 分量：$\omega' = 0.375\pi \times 4 = 1.5\pi$。但主值区间是 $[-\pi, \pi]$，$1.5\pi$ 等效于 $-0.5\pi$。所以它会卷绕回来，出现在 $\omega' = -0.5\pi$ 处，这对应模拟频率 -2000 Hz，也就是正频率 2000 Hz（注意离散信号的对称性）。实际上，它在 4000 Hz 采样系统里是 2000 Hz 的假信号。

更糟的是，还有其他平移副本。比如 $k=1$ 的副本 $X(e^{j(\omega - 2\pi)/4})$，当 $\omega' = 0.5\pi$ 时，内部参数为 $(0.5\pi - 2\pi)/4 = -1.5\pi/4 = -0.375\pi$，正好对应原信号 $-\omega_2 = -3000\text{ Hz}$ 的镜像！这个副本叠加进来，会在 $\omega'=0.5\pi$ 处产生一个强混叠分量，完全破坏原 1000 Hz 的信号。

**这就是为什么必须先抗混叠滤波。** 在 M 倍抽取前，必须把 $|\omega| > \pi/M$ 的成分衰减到可忽略的程度。所以**抽取的正确顺序永远是“先滤波，后下采样”**。

---

### 2. 内插（Interpolation）—— 升采样 L 倍

内插是抽取的逆过程，提高采样率。

#### 2.1 时域操作
内插因子为 $L$（正整数）。
- 第一步：**上采样（插零）**。在原序列每个样点之间插入 $L-1$ 个零值，得到 $w[n]$。
$$
w[n] = \begin{cases}
  x[n/L] & n = 0, \pm L, \pm 2L, \dots \\
  0 & \text{其它}
  \end{cases}
$$

  此时采样率名义上已变为 $f_s' = L \cdot f_s$。
- 第二步：**抗镜像低通滤波**。用滤波器去掉插零产生的多余镜像，还原出平滑波形。

#### 2.2 频域推导
由 $w[n]$ 的定义直接求频谱：
$$
W(e^{j\omega}) = \sum_{n} w[n] e^{-j\omega n} = \sum_{m} x[m] e^{-j\omega (L m)} = X(e^{j\omega L})
$$

这里 $\omega$ 是**相对于新采样率 $f_s'$** 的归一化频率。

**内插带来的频谱变化：**

1.  **压缩（收缩）**：原频谱的横轴被缩放因子 $L$ 压缩。原信号在 $X$ 中占据 $0 \sim \pi$ 的整个频带，现在沿新 $\omega$ 轴被压缩到了 $0 \sim \pi/L$ 之内。也就是说，在 $-\pi \sim \pi$ 的区间里，信号的基带**只占中间一小部分**。

2.  **产生镜像**：由于频谱本质是以 $2\pi$ 为周期的，压缩后，原 $X(e^{j\omega})$ 中在 $0\sim 2\pi$ 内的谱，现在出现在 $W(e^{j\omega})$ 的 $0 \sim 2\pi/L$ 中。但区间 $\pi/L \sim 3\pi/L$，以及 $-\pi/L \sim -3\pi/L$ 等位置，会以 $\pi/L$ 为对称轴，出现**镜像频谱**。这些镜像与基带谱形状完全一样，必须由后续低通滤波滤除。

#### 2.3 举例：L=2 倍内插
原信号：1000 Hz 正弦波，采样率 $f_s = 4000\text{ Hz}$。归一化频率 $\omega_1 = 2\pi \times 1000/4000 = 0.5\pi$。频谱在 $0.5\pi$ 和 $-0.5\pi$ 处各有一根谱线。
进行 L=2 上采样，输出采样率 $f_s' = 8000\text{ Hz}$。
$$
W(e^{j\omega}) = X(e^{j2\omega})
$$

原 $0.5\pi$ 处谱线被映射到：$2\omega = 0.5\pi \Rightarrow \omega = 0.25\pi$。同时原 $-0.5\pi$ 映射到 $-0.25\pi$。此时在 $0.25\pi$ 和 $-0.25\pi$ 出现了基带。
那么原来的周期延拓呢？$X(e^{j\omega})$ 在 $\omega=1.5\pi$（即 $-\pi$ 前面的周期）也有谱线，现在变成 $2\omega = 1.5\pi \Rightarrow \omega = 0.75\pi$。所以在 $0.75\pi$ 和 $-0.75\pi$ 处也各有一根谱线。
在 8000 Hz 系统下，$0.25\pi$ 对应 1000 Hz，$0.75\pi$ 对应 3000 Hz。这 3000 Hz 就是**镜像**。从模拟角度看：4000 Hz 采样的 1000 Hz 信号，插零后，相当于在 8000 Hz 采样下同时存在 1000 Hz 和 3000 Hz（以及 5000 Hz、7000 Hz…）的等幅分量。
随后的低通滤波器（增益为 L，截止在 $\pi/L$，这里是 $\pi/2$）恰好只保留 $0 \sim 0.5\pi$ 的基带，滤掉镜像，就得到了平滑的 8000 Hz 采样信号。

**所以内插的正确顺序永远是“先插零，后滤波”**，否则根本无法产生那些需要被滤掉的镜像。

### 3. 归一化频率变换小结口诀

- **抽取 M 倍**：归一化频谱沿 $\omega$ 轴**拉伸 M 倍**，并叠加上 M-1 个平移副本。  
  若原始信号归一化带宽为 $B_\omega$（单位：弧度/样本），则无混叠抽取的条件是 $M \cdot B_\omega \le \pi$，即 $B_\omega \le \pi/M$。
- **内插 L 倍**：归一化频谱沿 $\omega$ 轴**压缩 L 倍**，并在 $[-\pi, \pi]$ 内填满 L-1 个镜像。  
  若原始信号归一化带宽为 $B_\omega$，内插后基带占据 $B_\omega/L$，镜像对称在 $\frac{2\pi k}{L} \pm \frac{B_\omega}{L}$ 处。

这些规则就像交通法规，半带滤波器和 CIC 滤波器正是因为严守了这些频域变化规律（加适当的通带/阻带设置），才能以极低的成本完成干净的采样率转换。现在你再去看 CIC 和半带的设计，应该能一眼看出它们的阻带就是为了精准切除那些混叠副本或镜像而放置的。
## 我的理解：传送门
在抽取中，其实可以把-pi到pi看作是两个传送门，抽取过程中，频谱在慢慢变胖，直到超出pi或者-pi时，就会从另一边回来，就像传送门一样，是吗？比如超出pi的部分就会从-pi那里伸入这个空间。

你的这个理解**非常准确，而且直觉上极其精妙**。“传送门”这个比喻，把抽取混叠的本质抓得活灵活现。我们顺着这个比喻，把它和数学公式、以及抗混叠滤波器的设计彻底打通。

---

### 1. 传送门是什么？

离散时间信号的频谱，天生就是以 $2\pi$ 为周期的。所以你可以把 $-\pi$ 和 $\pi$ 这两个点想象成**一面环形墙的两端**——它们是粘在一起的。频谱在这段区间内活动，一旦从右边越过 $\pi$，就等同于从左边 $-\pi$ 钻了出来。这就是你所说的“传送门”。

### 2. 抽取时，“慢慢变胖”的真正含义

对于抽取因子 $M$，我们在**原归一化频率轴 $\Omega$**（范围 $-\pi \sim \pi$）上看整个过程，是最容易理解传送门的。

假设原信号有一个单频分量，位于 $\Omega = \Omega_0$。

**抽取的“变胖”**，指的是下采样操作把这个频率 **拉伸了 $M$ 倍**，把它映射到了一个新位置：
$$
\Omega' = M \cdot \Omega_0
$$

现在关键来了：这个新的 $\Omega'$ 可能已经不在 $[-\pi, \pi)$ 里了。比如 $M=4$，$\Omega_0 = 0.4\pi$，那么 $\Omega' = 1.6\pi$。

这时，“传送门”就启动了。因为离散频谱的世界里，任何频率都可以加减整数倍的 $2\pi$。所以 $1.6\pi$ 实际上等价于：
$$
1.6\pi - 2\pi = -0.4\pi
$$

它就**瞬间从 $\pi$ 的右门穿出，从 $-\pi$ 的左门穿了回来**，落在了 $-0.4\pi$ 处。在频谱图上，本来在 $0.4\pi$ 的一根谱线，抽取后变成了一根在 $-0.4\pi$ 的谱线。对于一个实信号而言，正负频率成对出现，这就意味着一个高频信号“伪装”成了一个低频信号——这就是混叠。

### 3. 整个过程就是“穿越传送门”

你可以想象，原信号在 $\Omega$ 轴上的整个频谱分布，就像一段有宽度的布。抽取操作抓着这块布的两端，将其沿着频率轴**拉长 $M$ 倍**。布被拉长后，中间部分会向外膨胀。一旦某一部分超出了 $\pi$ 这个传送门，多出来的那段布并不会消失，而是立刻从 $-\pi$ 这个门原样挤回观察区间，然后继续往里挤。随着 $M$ 的增大，频谱会被反复拉长、穿越回、再叠加，最终在新奈奎斯特区间 $[-\pi, \pi]$ 里揉成一团。

### 4. 传送门的“门框”在哪儿？——滤波器阻带的选取

既然穿越传送门是混叠的罪魁祸首，那我们就要问：**信号里哪些分量，在拉伸 $M$ 倍之后，会第一脚跨过 $\pi$ 这个门？**

答案是：原信号中所有满足 $M \cdot |\Omega| > \pi$ 的频率分量，也就是所有 $|\Omega| > \pi/M$ 的分量，都会被拉伸得越过门。

因此，$\pi/M$ 就是**传送门的“门框”**。在这个门框之外的原信号能量，在抽取后无一例外都会穿越传送门，混进基带 $[-\pi/M, \pi/M]$，并且和那里的原生信号永久叠加，无法分离。

所以，抗混叠滤波器的工作，就是**在抽取开关启动之前，把 $\pi/M$ 这个门框之外的能量全部剪除**。它的阻带，必须从 $\pi/M$ 开始，一直覆盖到 $\pi$。这样一来，被拉伸的频谱在到达传送门时，已经没有任何凸出的部分能够穿过去，混叠就不会发生。

### 5. 与内插的传送门对比

这个比喻同样适用于内插，不过是反向的：

- **抽取**：先滤波（剪掉门框外），再拉长。如果没有剪掉，拉长时多余部分会**从外面穿越传送门挤进来**，污染内部。
- **内插**：先压缩，频谱变窄，在内部腾出空间。但压缩后的频谱在 $[-\pi, \pi]$ 内，除了中间的压窄的基带外，其他区域是“空的”。然而，压缩操作本身会在 **内部自动生成镜像副本**，这些副本恰好对称地填充在 $\pi/L, 3\pi/L$ 等位置。对于内插来说，**没有穿越传送门的过程**，混叠是在区间内部凭空产生的镜像。随后的滤波器直接把内部的这些镜像滤掉即可。
