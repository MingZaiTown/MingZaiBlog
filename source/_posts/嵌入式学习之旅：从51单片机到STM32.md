## 前言

大一的时候第一次接触单片机，从经典的 **STC89C52**（51单片机）开始，一路学到现在的 **STM32**，中间踩过不少坑，也积累了一些经验。这篇文章分享一下我的学习路线和心得。

## 第一阶段：51单片机

51单片机虽然架构老旧，但是作为入门非常合适：

- **寄存器少**，datasheet 只有一两百页，不像 STM32 动辄上千页
- **外设简单**，GPIO、定时器、串口，基础但够用
- **Keil + C51** 开发环境好搭建

入门项目：
1. 点亮 LED（嵌入式世界的 Hello World）
2. 按键控制LED
3. 数码管动态扫描
4. 串口通信（与电脑收发数据）
5. DS18B20 温度传感器

## 第二阶段：过渡到 STM32

从 51 到 STM32 的第一个门槛是**环境搭建**：

| 项目 | 51单片机 | STM32 |
|------|---------|-------|
| 内核 | 8051 (8位) | Cortex-M3/M4 (32位) |
| 主频 | 12MHz | 72MHz+ |
| 开发方式 | 寄存器直接操作 | HAL库/标准库 |
| 调试 | 仿真器很少用 | SWD/JTAG 必备 |

推荐直接从 **HAL库 + CubeMX** 开始，不要一上来就怼寄存器，容易劝退。

## 第三阶段：实战项目

理论学再多不如做一个完整项目。我当时做了一个 **智能温控风扇**：

- STM32F103C8T6 作为主控
- DS18B20 采集温度
- L298N 驱动直流电机
- OLED 显示实时数据
- 串口上报到 PC

代码框架：

```c
int main(void) {
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_USART1_UART_Init();
    MX_I2C1_Init();

    while (1) {
        temp = DS18B20_ReadTemp();
        OLED_ShowTemp(temp);
        Fan_Control(temp);
        HAL_Delay(1000);
    }
}
```

## 总结

嵌入式的学习曲线确实比较陡，但只要动手做项目，进步会很快。下一步计划学习 **FreeRTOS** 和 **FPGA**，到时候再写文章分享。
